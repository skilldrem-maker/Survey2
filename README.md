# Survey2 — Personal Storage Hub

Central storage hub for organizing projects, learning materials, school work, documents, and automation notes.

## Structure

- `01-projects/` — startup and software projects
- `02-learning/` — learning plans, notes, exercises, and references
- `03-school/` — school subjects, assignments, study material, and exam preparation
- `04-documents/` — reusable documents and general records
- `05-automation/` — automation workflows, prompts, and system instructions
- `06-archive/` — older material kept for reference
- `robotics/` — robotics-specific workspace

## Operating principle

Survey2 is the storage hub. ChatGPT acts as the Key Supervisor and can coordinate organization, retrieval, updates, and connected workflows when access is available.
