The SOF page currently uses ISO wording in some current-cycle material, although the path still contains NSO. This pack refers to it as NSO/ISO so the folder remains easy to find.

## Limits

- Sample papers are used to understand question style and exam pattern, not to copy protected questions.
- The practice pack contains original practice questions and explanations; it is not an official SOF resource.
