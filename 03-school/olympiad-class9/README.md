# Class 9 Olympiad Full-Marks Practice Pack

**Scope:** SOF IMO + SOF NSO/ISO, Class 9, 2026–27 syllabus cross-checked against official SOF pages. This is an original practice resource, not an official SOF publication and not a guarantee of a particular score.

## How to use
- Work one chapter worksheet in about 10–20 minutes depending on difficulty.
- Do not look at the answer key while solving.
- Mark each answer: ✓ sure, ? guessed, ✗ wrong.
- For every wrong/guessed answer, write the rule or concept that fixes the mistake.
- Reattempt wrong questions after 1 day, 3 days, and 7 days.
- Every 3–4 days, take a timed mixed test and review errors.

## Target worksheet design
Each chapter bank should grow to **20–30 questions**:
- 5 foundation / concept checks
- 8 standard MCQs
- 5 multi-step / application questions
- 2–5 Olympiad HOTS questions
- Separate answer key with reasoning and calculation steps
- A short “common traps” note

## Quality rules
1. Use original questions and do not copy whole questions from copyrighted sample papers.
2. Every question must have one unambiguous best answer unless explicitly labelled multi-select.
3. Recalculate numerical answer keys and check option letters before release.
4. Keep question paper and key in separate sections/files for realistic practice.
5. Update the tracker only after the chapter’s question bank and key have been checked.
