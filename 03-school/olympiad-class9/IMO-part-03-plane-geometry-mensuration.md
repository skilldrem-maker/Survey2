# IMO Practice Bank — Part 3: Geometry and Mensuration
Class 9 • 10 original questions per chapter

## 10. Quadrilaterals
1. Sum of interior angles of a quadrilateral: A 180° B 270° C 360° D 540°
2. A parallelogram has one angle 70°. An adjacent angle is: A 70° B 90° C 110° D 140°
3. Diagonals of a rectangle are: A unequal always B equal C perpendicular always D angle bisectors always
4. A quadrilateral with exactly one pair of parallel sides is a: A kite B trapezium/trapezoid C rhombus D square
5. Opposite sides of a parallelogram are: A equal and parallel B perpendicular C unequal always D curves
6. A rhombus has all sides: A equal B right angles always C unequal D parallel to diagonals
7. Each angle of a rectangle is: A 45° B 60° C 90° D 120°
8. A square is also a: A rectangle and rhombus B trapezium only C circle D triangle
9. If one angle of a parallelogram is 125°, its opposite angle is: A 55° B 65° C 125° D 235°
10. The diagonals of a parallelogram: A bisect each other B are always equal C are always perpendicular D never meet

5. If triangle base doubles and height stays same, area: A halves B doubles C quadruples D unchanged
6. Two triangles on equal bases and between same parallels have: A equal areas B different perimeters only C equal angles always D equal sides always
7. Area of triangle with base 15 cm and height 4 cm: A 19 B 30 C 60 D 120 cm²
8. A parallelogram has base 9 cm and area 72 cm². Height: A 6 B 8 C 9 D 12 cm

10. Two parallelograms on the same base and between the same parallels have: A equal areas B equal perimeters C equal diagonals D identical shapes

## 12. Circles
1. Diameter of a circle of radius 7 cm: A 3.5 B 7 C 14 D 49 cm
2. Equal chords of the same circle subtend at the centre: A equal angles B supplementary angles always C right angles always D no angles
3. Perpendicular from the centre to a chord: A bisects the chord B doubles chord C is parallel to chord D always equals radius
4. A chord passing through the centre is a: A tangent B diameter C arc D sector
5. If radius doubles, circumference becomes: A half B double C triple D four times
6. Angle subtended by a diameter at a point on the circle is: A 45° B 60° C 90° D 180°
7. A tangent to a circle is perpendicular to the radius at: A any point B point of contact C centre only D no point

9. If two radii are 5 cm, diameter is: A 2.5 B 5 C 10 D 25 cm
10. Equal chords in the same circle are: A equidistant from centre B always parallel C diameters always D tangent lines

## 14. Constructions
1. To construct the perpendicular bisector of a segment, compass arcs should have radius: A less than half the segment B more than half the segment C zero D exactly zero
2. An angle bisector divides an angle into: A two equal angles B two right angles always C three equal parts D unequal angles

4. Which is essential to construct a 60° angle with compass and straightedge? A equal-radius arcs B protractor reading only C calculator D graph paper only
5. A perpendicular from a point to a line makes an angle of: A 30° B 45° C 90° D 180°
6. A triangle can be constructed from sides 3,4,5 because: A 3+4>5 B 3+4<5 C all sides equal D angles all 90°
7. An angle of 90° can be constructed by: A constructing a perpendicular B drawing any ray C copying a 30° angle only D measuring length
8. The perpendicular bisector of a segment contains points: A equidistant from endpoints B closer to one endpoint always C on the segment only D with zero distance
9. To copy an angle accurately with compass, transfer: A arc and chord distance B only the angle label C line colour D page size
10. Which data generally determine a unique triangle? A three side lengths satisfying triangle inequalities B one side only C three angles only without scale D two unrelated lengths
